# Abdullah Malik — Portfolio Website

A personal portfolio site for Abdullah Malik, a full-stack developer from Lahore, Pakistan. Built with plain HTML, CSS, and JavaScript — no frameworks, no build step.

## Live Sections

- **Home** — intro, typewriter role animation, profile photo
- **About** — bio and quick stats
- **Skills** — animated skill bars
- **Services** — what's offered (web dev, APIs, bots, Android apps, scripts)
- **Contact** — email and social links

## Setup

No build tools or dependencies required.

1. Add `profile.png` and `favicon.ico` to the `assets/` folder.
2. Open `index.html` directly in a browser, or deploy the whole folder to any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.).

## Editing

- **Text content** — edit directly in `index.html`.
- **Colors / spacing / fonts** — edit `css/styles.css` (theme variables are at the top under `:root`).
- **Behavior** (menu, scroll animations, typewriter phrases) — edit `js/app.js`.
